# 模型卡 · 成都住宅单价的空间解释力

> 一句话：**在同一个区里，这套特征能解释 16% 的「谁比谁贵」；随机切分的 34.9% 是假的。**

---

## 1. 这个模型是干什么的

不是房价预测器。它回答一个更窄、但更专业的问题：

> 把「你在哪个区」这个最强的价格因素先扣掉之后，**区位可达性、社区形态、配套档次三者各自还能解释多少**？

用途是解释与诊断（哪类因素在起作用、模型在哪些片区系统性看错），不是给出一个可交易的估价。

## 2. 数据

| 项 | 内容 |
|---|---|
| 价格 | 链家小区挂牌参考均价，**2017-08-30** 快照，10 078 个小区 |
| 坐标 | 通过**小区名称**关联到 OSM 住宅面质心（W10 成果），命中率 9.6% |
| 特征 | W10 设施/地铁站/区县（2026-11 OSM 快照）+ 链家属性字段 |
| 有效样本 | **525 个住宅小区**，5 个中心城区（金牛 135 / 武侯 124 / 成华 122 / 青羊 84 / 锦江 60），96 个片区 |
| 许可 | 价格数据仅研究学习用；地图数据 © OpenStreetMap contributors, ODbL |

**已知的时间错位**：价格 2017，设施 2026。处理方式是目标变量改用「区内相对价」，把城市级水平漂移整体消掉——不是消除问题，是不让它污染系数。这一条在 README 与本节都写了一次，因为它是这份成果最容易被质疑的地方。

## 3. 目标变量

```
y = z( log(单价) | 区县内 )      均值/标准差只用训练折估计
```

含义：1 个单位 = 该区县 1 个标准差。R² 因此只衡量「区内差异」的解释份额，不含区县之间的贵贱。

## 4. 指标（按测试集样本数加权的 5 折均值）

| 模型 | 随机 5 折 | 按片区分组 | 按区县分组 |
|---|---|---|---|
| 基线（区内均值） | -0.024 | -0.025 | -0.176 |
| 线性（岭回归 α=1） | -0.324 | -0.104 | -0.609 |
| 梯度提升树 | **+0.349** | +0.267 | **+0.162** |

- **关键差值**：随机 0.349 vs 按区县 0.162 → **虚高 18.8 个百分点**（相对 0.162 而言是 2.2 倍）
- 基线在按区县切分时是 -0.176：说明「一个从没见过的区」，连它的均价水平都预测不了——这恰恰是按区县分组交叉验证的真实难度
- 线性模型全线为负：26 个特征里有成组共线（五类距离、一堆 one-hot），目标又已经去掉了区县均值，线性加性假设在这份数据上不成立。这不是代码 bug，是结论

## 5. 特征组消融：空间 vs 属性

| 特征组 | 个数 | 随机 5 折 | 按区县分组 |
|---|---|---|---|
| 只用空间类（可达性 + 密度） | 10 | -0.074 | **-0.579** |
| 只用属性类（形态 + 配套） | 16 | +0.258 | +0.096 |
| 全用 | 26 | +0.349 | +0.162 |

**这是本卡最重要的一段**：只给空间特征，按区县切分时比基线还差 0.58。原因不难想——经过区内去均值后，可达性特征里剩下的主要是「区县位置」的代理（到天府广场距离、地铁站密度天然随区变化），跨区外推时这些特征既解释不了区内差异、还会把模型带偏。空间信息要在区内价差上起作用，得靠更细的东西（学区、商圈成熟度、微观路网），这些我们没有。

## 6. 谁在起作用（置换重要性，按区县 5 折测试集）

| 特征 | 重要性（R² 下降） |
|---|---|
| 物业费 | 0.543 ± 0.092 |
| 楼龄（至 2017） | 0.067 |
| 住宅片区面积 | 0.062 |
| 到天府广场 | 0.033 |
| 户数（对数） | 0.029 |
| 到最近医疗设施 | 0.017 |
| 1 km 设施数 | -0.013（噪声） |

物业费一项顶掉其余全部——它就是「小区档次」的代理变量。空间类特征整体排在属性类之后。

## 7. 残差诊断

- 按区县分组 OOF 残差 **Moran's I = 0.2337，p = 0.001（999 次置换，8 邻域 KNN 行标准化）**
- 结论：残差仍成团。模型没吃干净空间结构，缺的正是上节说的细颗粒空间变量
- 片区级系统性偏差（样本 ≥8 的片区中位数）：东苑 **+37%**（低估）、驷马桥 **−22%**（高估）
- 区县均值偏差：青羊 +17.3%、武侯 +12.6%、锦江 +8.2%、金牛 −5.0%、成华 −8.7%

## 8. 五条已知局限

1. **样本量 525，覆盖 5 个中心城区**。近郊（新都、龙泉驿）因区内样本 <20 被整区剔除，因此结论只适用于主城区
2. **坐标来自名称关联，命中率 9.6%**。能挂上的多是有名、成规模的小区，老旧小小区与单位宿舍基本缺失——样本存在系统性偏向
3. **价格 2017、设施 2026**。区内相对价缓解了水平漂移，但没有解决「2017 年的地铁站数量与 2026 不同」
4. **缺少最关键的三个变量**：学区、商圈成熟度、房龄/装修的实际状态。残差成团就是对这三者的抗议
5. **置换重要性不是因果**。物业费重要，不等于涨物业费能涨房价

## 9. 不可用途声明

**不可用于**：任何形式的定价、估值、投资建议、买卖决策、信贷评估，以及任何对外发布的「片区房价排名」。
**可用于**：方法演示、特征工程教学、空间交叉验证的必要性论证、以及「哪些变量我们还没拿到」的清单。

## 10. 复现

```
python run_model.py        # 四段全跑，末尾自动做四处一致性检查
```

固定 `random_state=42`；台账在 `build/match_log.json`、`build/feature_log.json`、`build/cv_results.json`。
